# SERVYRA — V2

SERVYRA est une plateforme de mise en relation locale : une demande, qualification, matching et mise en relation avec des professionnels.

## Ce qui est inclus
- accueil mobile-first
- création de demande et classification locale
- API de matching initiale
- catalogue de professionnels de démonstration
- espace pro de démonstration
- espace propriétaire `/admin`
- simulation de suivi de l’intelligence/matching
- modèle économique avec commission cible de 10 %
- endpoint Stripe Checkout prêt à recevoir `STRIPE_SECRET_KEY`
- modèle PostgreSQL dans `db/schema.sql`
- pages de base CGU, confidentialité et mentions légales
- guide de déploiement téléphone

## Important avant lancement public
Les comptes réels, la base de données, le stockage privé, la vérification des utilisateurs, le webhook Stripe, les vrais professionnels et les documents juridiques doivent être connectés/configurés avant d'accepter de vraies transactions.

Aucune clé secrète n'est incluse dans ce projet.
